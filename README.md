# NFC Tapeador

Catálogo moderno para productos NFC con carrito y backend Supabase.

## Desarrollo
1. `npm install`
2. Copiar `.env.example` a `.env.local` y completar las variables públicas de Supabase.
3. `npm run dev`

## Documentación
Revisa `docs/ARCHITECTURE.md`, `docs/DECISIONS.md` y `docs/KNOWN_ISSUES.md` antes de cambios estructurales.
